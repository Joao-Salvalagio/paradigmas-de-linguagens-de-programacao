## Resumo sobre Paradigmas de Linguagens de Programação

### O que são Paradigmas?

Paradigmas de linguagens de programação são conjuntos de princípios, práticas e metodologias que definem como estruturar e resolver problemas através de código. Cada paradigma oferece uma perspectiva diferente sobre como abstrair e organizar computações.

### Paradigmas Principais

#### 1. **Imperativo/Procedural**
O paradigma imperativo foca em **como** resolver um problema através de uma sequência explícita de comandos e instruções. O programa é visto como uma série de passos que modificam o estado do sistema. Linguagens como C, Pascal e Python (que suporta este paradigma) usam variáveis para armazenar estado e funções para executar ações específicas.

- **Características:** sequência de comandos, variáveis mutáveis, controle de fluxo explícito
- **Vantagens:** direto e intuitivo, fácil de entender o fluxo de execução
- **Desafios:** código pode ficar complexo em projetos grandes

#### 2. **Orientação a Objetos (OOP)**
A orientação a objetos organiza o código em torno de **objetos** que encapsulam dados (atributos) e comportamentos (métodos). Promove reutilização através de herança, polimorfismo e encapsulamento. Linguagens como Java, C++, Python e C# são amplamente orientadas a objetos.

- **Características:** classes, herança, polimorfismo, encapsulamento
- **Vantagens:** modularidade, reutilização de código, escalabilidade
- **Desafios:** overhead de complexidade em programas simples

#### 3. **Funcional**
O paradigma funcional trata computação como avaliação de funções matemáticas, evitando mudanças de estado e dados mutáveis. Enfatiza imutabilidade e usa conceitos como first-class functions, higher-order functions e recursão. Linguagens como Haskell, Lisp, Scheme e Rust (que oferece suporte funcional) exemplificam este paradigma.

- **Características:** funções puras, imutabilidade, composição de funções
- **Vantagens:** previsibilidade, facilita testes e paralelização
- **Desafios:** curva de aprendizado maior para programadores acostumados com imperativos

#### 4. **Lógico**
O paradigma lógico baseia-se em lógica formal e programação em restrições. Um programa consiste em fatos e regras, e a máquina deduz soluções através de inferência. Prolog é o exemplo clássico deste paradigma.

- **Características:** fatos, regras, inferência, backtracking
- **Vantagens:** adequado para problemas de inteligência artificial, resolução de restrições
- **Desafios:** menor aplicabilidade em sistemas gerais, comunidade menor

---

## Conclusão

Os diferentes paradigmas oferecem ferramentas distintas para resolver problemas computacionais. A escolha do paradigma adequado depende da natureza do problema, dos requisitos do projeto e das preferências da equipe de desenvolvimento.
